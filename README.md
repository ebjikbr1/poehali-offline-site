# Поехали — HTML-версия «Блокнота машиниста»

Рабочая HTML-версия с картой профиля, скоростями по категориям поездов, предупреждениями, настройками и расчётами. Данные маршрута находятся в проекте; для работы карты внешний сервер данных не нужен.

## Запуск и офлайн-режим на телефоне

Для установки как приложения разместите содержимое репозитория на HTTPS-хостинге статических файлов. Откройте `poehali.html` на телефоне при наличии сети, дождитесь появления карты, затем добавьте страницу на главный экран через меню браузера. Service worker сохраняет HTML, скрипты, стили, карту, скорости, справку и изображения. После первой полной загрузки установленное приложение открывается без сети. Пользовательские записи хранятся локально в браузере телефона; не удаляйте данные сайта, если хотите их сохранить.

Исходный адрес `127.0.0.1` с компьютера на телефоне не работает. GitHub-репозиторий сам по себе не является адресом приложения: для установки нужен отдельный HTTPS-сайт, например GitHub Pages при подходящих настройках репозитория.

`poehali.html` также содержит встроенные код и данные карты и может служить отдельной копией режима «Поехали». Для полного приложения с остальными разделами используйте сайт со всеми файлами.

## Разработка

```text
python -X utf8 scripts/build_standalone.py
npm test
```

`index.html` — полное приложение; `poehali.html` — отдельный экран «Поехали». Файл `poehali.html` формируется из исходников скриптом сборки.
