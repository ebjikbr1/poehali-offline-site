# Поехали — HTML-версия «Блокнота машиниста»

Рабочая HTML-версия с картой профиля, скоростями по категориям поездов, предупреждениями, настройками и расчётами. Данные маршрута находятся в проекте; для работы карты внешний сервер данных не нужен.

## Запуск и офлайн-режим на телефоне

Сайт: https://ebjikbr1.github.io/poehali-offline-site/poehali.html

Откройте этот адрес на телефоне при наличии сети, дождитесь появления карты, затем добавьте страницу на главный экран через меню браузера. Service worker сохраняет HTML, скрипты, стили, карту, скорости, справку и изображения. После первой полной загрузки установленное приложение открывается без сети. Пользовательские записи хранятся локально в браузере телефона; не удаляйте данные сайта, если хотите их сохранить.

Исходный адрес `127.0.0.1` с компьютера на телефоне не работает. Для установки используйте адрес сайта выше, а не страницу с кодом репозитория.

`poehali.html` также содержит встроенные код и данные карты и может служить отдельной копией режима «Поехали». Для полного приложения с остальными разделами используйте сайт со всеми файлами.

## Разработка

```text
python -X utf8 scripts/build_standalone.py
npm test
```

`index.html` — полное приложение; `poehali.html` — отдельный экран «Поехали». Файл `poehali.html` формируется из исходников скриптом сборки.
